# BOC: Business Over Chat

A clickable web simulation of BOC, one chat app where Indian businesses of every type sell, buy, get paid, ship and sign, plus the BOC team's admin console. All names, numbers and businesses are example data.

- App: `prototype/index.html`  
- Admin console: `prototype/admin.html`  
- Product brief: `PRODUCT.md`, design system: `DESIGN.md`, specs and plans: `docs/`

Run locally: `node tools/serve.mjs` then open http://127.0.0.1:5174

Tests: open `prototype/index.html?test=smoke,app,wiring,fixes` or `prototype/admin.html?test=admin`.
